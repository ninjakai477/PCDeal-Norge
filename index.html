Om PCDeal Norge

PCDeal Norge er et uavhengig prosjekt for sammenligning av PC-komponenter. Tjenesten er under oppbygging, og utvalget kan være begrenset mens vi kobler til godkjente datakilder.

Reklame og affiliatelenker: Noen utgående lenker kan være annonselenker som gir oss provisjon ved kjøp, uten ekstra kostnad for deg. Dette opplyses der det er aktuelt. Vi er ikke tilknyttet butikkene som vises.

Priser og personvern: Historiske lavpriser viser kun egne registreringer, ikke hele markedet. Denne statiske siden krever ikke innlogging og samler ikke inn personopplysninger via egne skjemaer. GitHub Pages og eksterne butikker kan behandle tekniske data i henhold til sine egne vilkår.
